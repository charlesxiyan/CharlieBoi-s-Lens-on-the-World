    ## Approach: Dijkstra + Min Heap

    This problem can be treated as a **shortest path problem on a grid**.

    Each cell `(row, col)` is a node, and each node can connect to at most four neighbors:

    ```text
    up, down, left, right
    ```

    Unlike a normal graph problem, we do not need to explicitly build an adjacency list. The neighbors of each cell can be generated directly using four directions.

    ## Graph Representation

    For a grid with:

    ```python
    m = len(heights)
    n = len(heights[0])
    ```

    there are:

    ```text
    m × n nodes
    ```

    Each cell:

    ```text
    (row, col)
    ```

    represents one node.

    Instead of building an adjacency list, define four directions:

    ```python
    Directions = [
        (1, 0),
        (-1, 0),
        (0, 1),
        (0, -1)
    ]
    ```

    For the current node `(curRow, curCol)`, a neighbor can be generated by:

    ```python
    nextRow = curRow + rowDelta
    nextCol = curCol + colDelta
    ```

    Then check whether it is inside the grid:

    ```python
    0 <= nextRow < m and 0 <= nextCol < n
    ```

    Therefore, the grid itself can be viewed as an **implicit graph**.

    ## Definition of Effort

    The edge weight between two adjacent cells is their absolute height difference:

    ```python
    abs(
        heights[nextRow][nextCol]
        - heights[curRow][curCol]
    )
    ```

    However, the effort of an entire path is **not the sum of all edge weights**.

    It is the **maximum height difference along the path**.

    For example:

    ```text
    Edge differences:

    2 → 5 → 3
    ```

    The effort of this path is:

    ```text
    max(2, 5, 3) = 5
    ```

    not:

    ```text
    2 + 5 + 3 = 10
    ```

    Our goal is to find a path from the top-left cell to the bottom-right cell whose maximum edge difference is as small as possible.

    ## `minEffort` Matrix

    Create:

    ```python
    minEffort = [[float('inf')] * n for _ in range(m)]
    minEffort[0][0] = 0
    ```

    `minEffort[row][col]` represents:

    > The minimum possible effort required to travel from `(0, 0)` to `(row, col)`.
    >

    The starting point requires no effort:

    ```python
    minEffort[0][0] = 0
    ```

    All other cells are initially unreachable, so their efforts are initialized to infinity.

    ## Min Heap

    Initialize:

    ```python
    minHeap = [(0, 0, 0)]
    ```

    Each heap entry stores:

    ```text
    (effort, row, col)
    ```

    For example:

    ```text
    (3, 1, 2)
    ```

    means that the current known effort required to reach `(1, 2)` is `3`.

    Since `effort` is the first element of the tuple, Python's `heapq` always pops the state with the smallest effort first.

    ## Skip Outdated Heap States

    A cell may be pushed into the heap multiple times if a better path is discovered later.

    Therefore:

    ```python
    if curEffort > minEffort[curRow][curCol]:
        continue
    ```

    If:

    ```text
    curEffort > minEffort[curRow][curCol]
    ```

    then the heap entry is outdated because a better path to the same cell has already been found.

    We can safely skip it.

    This is the same **lazy deletion** idea used in standard Dijkstra.

    ## Relaxation

    Suppose we are currently at:

    ```text
    (curRow, curCol)
    ```

    and move to:

    ```text
    (nextRow, nextCol)
    ```

    First calculate the effort of this edge:

    ```python
    edgeEffort = abs(
        heights[nextRow][nextCol]
        - heights[curRow][curCol]
    )
    ```

    Since the effort of a path is the **maximum edge difference along that path**, the new path effort is:

    ```python
    newEffort = max(edgeEffort, curEffort)
    ```

    Then perform relaxation:

    ```python
    if newEffort < minEffort[nextRow][nextCol]:
        minEffort[nextRow][nextCol] = newEffort
        heapq.heappush(
            minHeap,
            (newEffort, nextRow, nextCol)
        )
    ```

    If the new path gives a smaller effort, update `minEffort` and push the new state into the heap.

    ## Why Dijkstra Still Works

    Standard Dijkstra minimizes:

    ```text
    sum of edge weights
    ```

    For example:

    ```python
    newDist = curDist + weight
    ```

    In this problem, we minimize:

    ```text
    maximum edge weight along the path
    ```

    Therefore, the relaxation formula changes to:

    ```python
    newEffort = max(curEffort, edgeEffort)
    ```

    The rest of the Dijkstra framework remains the same.

    ## Early Termination

    When the bottom-right cell is popped from the min heap:

    ```python
    if curRow == m - 1 and curCol == n - 1:
        break
    ```

    its minimum effort has already been determined.

    This is because Dijkstra always processes the state with the smallest current effort first.

    Therefore, we do not need to continue exploring the remaining nodes.

    Finally:

    ```python
    return minEffort[-1][-1]
    ```

    |  | 743 Network Delay Time | 1631 Minimum Effort Path |
    | --- | --- | --- |
    | Graph | Explicit graph | Grid / implicit graph |

    The main difference is the definition of the path cost.

    ### LeetCode 743

    ```python
    newDist = curDist + weight
    ```

    ### LeetCode 1631

    ```python
    newEffort = max(
        curEffort,
        abs(height1 - height2)

    ```

    The overall Dijkstra structure remains unchanged.

    ## Complexity

    Let:

    ```text
    V = m × n
    ```

    Each cell has at most 4 edges, so:

    ```text
    E = O(m × n)
    ```

    ### Time Complexity

    ```text
    O(m × n × log(m × n))
    ```

    Each node/edge may cause a heap operation, and each heap operation costs `O(log(m × n))`.

    ### Space Complexity

    ```text
    O(m × n)
    ```

    Used by:

    - `minEffort`
    - `minHeap`

## Python solution

```python
import heapq

class Solution:
    def minimumEffortPath(self, heights: List[List[int]]) -> int:
        m, n = len(heights), len(heights[0])
        Directions = [(1, 0), (-1, 0), (0, 1), (0, -1)]

        minEffort = [[float('inf')] * n for _ in range(m)]
        minEffort[0][0] = 0

        minHeap = [(0, 0, 0)]

        while minHeap:
            curEffort, curRow, curCol = heapq.heappop(minHeap)

            if curEffort > minEffort[curRow][curCol]:
                continue

            if curRow == m - 1 and curCol == n - 1:
                break

            for rowDelta, colDelta in Directions:
                nextRow = curRow + rowDelta
                nextCol = curCol + colDelta

                if 0 <= nextRow < m and 0 <= nextCol < n:
                    newEffort = max(
                        abs(
                            heights[nextRow][nextCol]
                            - heights[curRow][curCol]
                        ),
                        curEffort
                    )

                    if newEffort < minEffort[nextRow][nextCol]:
                        minEffort[nextRow][nextCol] = newEffort
                        heapq.heappush(
                            minHeap,
                            (newEffort, nextRow, nextCol)
                        )

        return minEffort[-1][-1]
```
