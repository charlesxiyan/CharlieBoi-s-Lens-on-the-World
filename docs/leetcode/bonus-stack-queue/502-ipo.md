# 502. IPO

*Edited by Charles*

**Hard · Python · Heap · Greedy · Sorting**

??? question "Problem"

    [Read the original problem on LeetCode](https://leetcode.com/problems/ipo/description/).

    Start with capital `w` and select at most `k` distinct projects. A project is available when its required capital is at most your current capital; finishing it adds its nonnegative profit. Maximize the final capital.

??? note "Explanation, examples & other approaches"

    ## Approach and Core Idea

    Sort projects by the capital needed to unlock them. Among all currently affordable projects, choose the largest profit. This gives at least as much capital as any other first choice, so it cannot reduce the set of projects available later.

    ## Algorithm Steps

    1. Sort `(capital, profit)` pairs and set a pointer `i` to the first unprocessed project.
    2. Before each choice, push every newly affordable profit into a max heap.
    3. Stop if no project is affordable.
    4. Pop the largest profit, add it to `w`, and repeat at most `k` times.

    ## Hand Simulation

    With `k = 2`, `w = 0`, profits `[1,2,3]`, and capital `[0,1,1]`, only profit `1` is initially available. Choose it: `w = 1`. Both remaining projects unlock; choose profit `3`. The final capital is `4`.

    ## Important Implementation Details

    Python’s `heapq` is a min heap, so store negative profits. Subtracting a popped negative number adds its profit. Capital is an eligibility threshold, not a cost subtracted from `w`. Each project is inserted once and popped at most once. Nonnegative profits make capital nondecreasing and justify keeping all unlocked projects in the heap.

    ## Time and Space Complexity

    For $N$ projects, sorting and heap work take $O(N\log(N+1))$ time overall; at most $N$ successful selections occur even if $k>N$. Auxiliary space is $O(N)$.

    ## Key Takeaways

    Use sorting to manage eligibility and a heap to choose the best eligible item.

## Python solution

```python
import heapq
class Solution:
    def findMaximizedCapital(self, k: int, w: int, profits: list[int], capital: list[int]) -> int:
        projects = sorted(zip(capital, profits))
        maxHeap = []
        l = len(projects)
        i = 0
        for _ in range(k):
            while i < l and w >= projects[i][0]:
                heapq.heappush(maxHeap, -projects[i][1])
                i += 1
            if not maxHeap:
                break
            w -= heapq.heappop(maxHeap)
        return w
```
